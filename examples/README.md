
The examples provided here correspond to several cases from our published articles.

They respectively represent:

**CsI**: SQE calculation for a simple system

**BAs**: The effect of BORN in calculation of SQE

**BAs_BORN_test_intel**: A minimal single-input smoke test for the BORN-enabled code path using `src/src_intel`

**PdSe₂**: SQE calculation for a complex system, simultaneously probing transverse and longitudinal waves in a single simulation

**TaS₂**: Multiple calculations to determine the optimal experimental strategy within a limited Q-space

**GaN**: 4D SQE calculation with slice visualization and line-slice plotting at individual q-points

**VO₂**: A case study on TDS calculation settings

**CN_TAS_resolution_test**: test of TAS resolution using the Cooper–Nathans method and a simplified 2D point-spread-function representation derived from the corresponding 4D resolution.

If you wish to quickly master the commonly used methods, we recommend starting by reproducing the CsI and PdSe₂ examples.
